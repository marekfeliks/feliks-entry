# FELIKS.FR — Entry site

The root-domain signpost page for feliks.fr. The main road sign links to https://marek.feliks.fr/.

## Deployment

In repository Settings → Pages, select Deploy from a branch, main and / (root). Then connect the custom domain feliks.fr after testing the default Pages URL.

Do not modify email DNS records (MX, SPF, DKIM, DMARC) while connecting GitHub Pages.

## Source

Standalone index.html. No build tools or external dependencies.
